# Pulse Studio

A Windows desktop app that shows the signal from an XD-58C pulse sensor connected to an Arduino Uno in real time: BPM, interval between beats, signal amplitude, signal quality, and the live PPG waveform with detected peaks marked.

Status: work in progress.

## Disclaimer

PPG measures changes in blood volume optically. It does not measure the electrical activity of the heart, and the heart animation in the app is only an illustration. This project is not a medical device and must not be used for diagnosis.

## Wiring

| Sensor | Arduino Uno |
|--------|-------------|
| S      | A0          |
| +      | 5V          |
| -      | GND         |
